# セットアップ手順

プログラムの経験がない方でも進められるように、1動作ずつ書いています。
**全部で1〜2時間**くらいです。途中でやめても、あとから続けられます。

⚠ 分からなくなったら、無理に進めず Issue で聞いてください。

## AIの契約は要りません

**この手順は、貼ってEnterを押すだけで最後まで進みます。**
ChatGPT や Claude などの有料の契約は要りません。

翻訳（やさしい日本語・英語・中国語・ベトナム語）は、
**Cloudflare に最初から付いてくる無料の機能**を使います。
別の契約も、APIキーも要りません。

AIの道具を持っている方は、もっと省けるところがあります。
→ [AIに手伝ってもらう.md](AIに手伝ってもらう.md)

---

## 用意するもの

- パソコン（Windows / Mac どちらでも）
- メールアドレス
- クレジットカード **は不要です**

あとから要るもの（急ぎません）:

- **独自ドメイン**（年1,000〜2,000円くらい）
  回覧をメールでも届けたい場合だけ要ります。
  メールを使わない（アプリの通知だけ）なら、最後まで無料です。

## ステップ1: Node.js を入れる

1. https://nodejs.org/ja を開きます
2. 左側の**「推奨版」**のボタンを押してダウンロードします
3. ダウンロードしたファイルを開き、画面の指示どおり「次へ」を押していきます

⚠ **Windowsの方は、もうひとつ入れてください。**
Windowsには `git` という道具が最初から入っていません。これが無いと、
ステップ3の1行目でいきなり止まります。

1. https://git-scm.com/download/win を開きます
2. ダウンロードされたファイルを開きます
3. 画面が何度も出ますが、**すべて何も変えずに「Next」**を押していきます
4. 最後に「Install」を押します

Macの方は要りません（最初から入っています）。

## ステップ2: Cloudflare のアカウントを作る

1. https://dash.cloudflare.com/sign-up を開きます
2. メールアドレスとパスワードを入れて「Sign Up」を押します
3. 届いたメールのリンクを押して、登録を完了します

## ステップ3: このアプリをパソコンに持ってくる

パソコンで「ターミナル」（Windowsなら「コマンドプロンプト」）を開き、
下の3行を**1行ずつ**貼り付けてEnterを押します。

```bash
git clone https://github.com/jagyamamoto/kairanban-app.git
```

```bash
cd kairanban-app
```

```bash
npm install
```

## ステップ4: Cloudflare にログインする

```bash
npx wrangler login
```

ブラウザが開くので、「Allow」を押します。

## ステップ5: データの保管場所を作る

```bash
npx wrangler d1 create kairanban
```

実行すると、画面に次のような文字が出ます。

```
database_id = "1234abcd-5678-..."
```

この **`"` で囲まれた部分をコピー**します。

続いて、写真を保存する場所も作ります。

```bash
npx wrangler r2 bucket create kairanban-images
```

## ステップ6: 設定ファイルに書き込む

`wrangler.jsonc` をメモ帳などで開き、次の場所を書き換えます。

| 探す文字 | 書き換える内容 |
| --- | --- |
| `"YOUR_D1_DATABASE_ID"` | ステップ5でコピーしたID |
| `"name": "kairanban"` | あなたの町会のアプリ名（英数字と `-` のみ。URLになります） |
| `"APP_NAME": "みどり町三丁目町会"` | あなたの町会の名前 |

## ステップ7: 町会の情報を書き込む

`src/shared/org.ts` を開き、`"` で囲まれた部分を書き換えます。
ファイルの中に説明が書いてあります。**書き換えるファイルは、これで最後です。**

- 町会の名前
- 会館の名前・住所・地図の位置
- 会員の区分の呼び名（「松柏会」「寿会」など地域の呼び方に）
- **地名・施設名の対訳表**（`glossary`）

### 地図の位置（緯度・経度）の調べ方

1. https://www.google.com/maps を開きます
2. 会館の場所を探して、そこを**右クリック**します
3. いちばん上に出る数字（例: `35.681236, 139.767125`）を押すとコピーされます
4. 左の数字を `lat`、右の数字を `lng` に貼り付けます

`areaPolygon`（地図に色を塗る範囲）は、**空のまま `[]` にしても構いません。**
その場合は地図に範囲の色が付かないだけで、ほかは普通に動きます。
あとから足せます。

### 対訳表（`glossary`）は必ず直してください

外国語に翻訳するとき、**AIが地名を別の実在の地名に訳してしまうこと**があります。
実際に、区名と神社名がよその土地の名前に置き換わった例がありました。
防災の案内で行き先が変わるので、実害になります。

分からなければ、**町会名と会館名の2つだけ**でも入れてください。

## ステップ8: 通知の鍵を作る

```bash
node tools/gen-vapid.mjs
```

画面に2つの鍵が出ます。

1. **公開鍵**を `wrangler.jsonc` の `"YOUR_VAPID_PUBLIC_KEY"` に貼り付けます
2. **秘密鍵**は、次のコマンドを実行してから貼り付けます（画面には残りません）

```bash
npx wrangler secret put VAPID_PRIVATE_KEY
```

## ステップ9: 合言葉を決める

```bash
npx wrangler secret put SESSION_SECRET
```

長いランダムな文字列（30文字以上）を入れてEnterを押します。

```bash
npx wrangler secret put SETUP_CODE
```

**最初の管理者になるための合言葉**です。自分だけが知っている文字列を入れます。
⚠ これを知っている人は管理者になれるので、人に教えないでください。

## ステップ10: 表に出す

```bash
npx wrangler d1 migrations apply kairanban --remote
```

```bash
npm run build && npx wrangler deploy
```

最後に出てくる `https://....workers.dev` が、あなたの町会のアプリのアドレスです。

## ステップ11: 自分を管理者にする

1. 出てきたアドレスをブラウザで開きます
2. `/admin` を後ろに付けて開きます（例: `https://....workers.dev/admin`）
3. ステップ9で決めた**合言葉**を入れます

これで管理者になれました。

## そのあとに設定するもの（あとからでOK）

### メールを送れるようにする

⚠ **ここだけは独自ドメインが要ります**（年1,000〜2,000円くらい）。
アプリの通知だけで足りるなら、この節は飛ばして構いません。あとから足せます。

⚠ 手順2はドメインの設定を変える作業です。**町会のホームページやメールが
止まることがあります。**不安なら、詳しい方に同席してもらってください。

1. https://resend.com でアカウントを作ります
2. 自分のドメインを登録し、表示されたDNSレコードを設定します
3. `npx wrangler secret put RESEND_API_KEY` でAPIキーを設定します
4. `wrangler.jsonc` の `MAIL_FROM` と `MAIL_REPLY_TO` を書き換えます

### ごみの日を載せる（ファイルは触りません）

**管理画面で書けます。ここでAIの契約は要りません。**

1. アプリを開いて、管理画面に入ります
2. 左のメニューの**「ページ」**を押します
3. **「+ 新しいページを作る」**を押します
4. **「スラッグ」**に `seikatsu` と入れます（半角の英数字）
5. **「タイトル」**に `ごみの日・防災` と入れます
6. **「本文」**に、**日本語で**ごみの収集日や避難所を書きます
   - 自治体のホームページの内容を、そのまま写して構いません
   - 出典（どこの何年何月の情報か）を最後に1行入れてください
7. **「下書きを作成」**を押します
8. 一覧に出てきたら、**「公開する」**を押します
9. **「翻訳を更新」**を押します

⚠ **スラッグに使えない言葉があります。**
`privacy` `kodomo` `nyukai` `yoyaku` は、アプリが別の画面に使っています。
ページのスラッグには使わないでください（`seikatsu` は使えます）。

これで、やさしい日本語・英語・中国語・ベトナム語のタブが自動で出ます。
内容を直したら、**そのつど「翻訳を更新」を押してください**（押さないと古い訳が残ります）。

> 翻訳はCloudflareの無料の機能でつくった機械翻訳です。
> 読める方が近くにいれば、一度目を通してもらうと安心です。

#### 区の多言語PDFまで並べたい場合（上級者向け）

`src/shared/lifeinfo.ts` を書き換えて `LIFE_INFO_ENABLED = true` にします。
表・カード・言語ごとのPDFリンクがそろった専用の画面になりますが、
**5言語ぶんを手で書くことになります。**
AIの道具がある方向けです → [AIに手伝ってもらう.md](AIに手伝ってもらう.md)

⚠ 中身は**すべて架空のサンプル**です。書き換えずに `true` にすると、
よその町の嘘の収集日が会員に出ます。`npm run check` で止まるようにしてあります。

### 自治体の防災メールを取り込む

`src/server/areaalerts.ts` の `ALERT_SOURCES` に、自治体が公開しているRSSを登録します。
既定では空なので、この機能は画面に出ません。

### 使い方ページ

`public/help/index.html` と `public/help/yakuin/index.html` はひな形です。
自分の町会の画面写真に差し替えてください。

⚠ **本物の会員情報が写った画面写真を置かないでください。**
このページはログインしなくても誰でも見られます。確認用のツールがあります:

```bash
bash tools/scrub-check.sh
```

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| `git` が見つからない | Windowsです。ステップ1の後半（git）をやってください |
| `npx` が見つからない | Node.js が入っていません。ステップ1からやり直してください |
| `npm install` が赤い字で止まる | Node.js が古いことが多いです。ステップ1をやり直し、パソコンを再起動してください |
| デプロイでエラー | `npx wrangler login` をもう一度実行してください |
| 画面が真っ白 | `npm run build` を実行してから `npx wrangler deploy` してください |
| `npm run check` で止まる | 画面に出ている日本語の説明のとおりに直してください。わざと止めています |
| 外国語のタブだけ日本語 | 管理画面の「ページ」で **「翻訳を更新」** を押していません |
| 生活情報のタブが出ない | 既定で切ってあります。ごみの日は「ページ」で載せてください（上の節） |
| 通知が来ない | ホーム画面のアイコンから開き、通知の確認で「許可」を押したか確認してください |

解決しないときは、Issue に**エラーの文字をそのまま**貼って質問してください。
