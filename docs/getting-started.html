はじめての方へ

自分の町内会用に、
セットアップする。

できるだけ簡単に始められるように、コピーして貼るだけの最初のプロンプトを 用意しました。AIコーディングツール（Claude Codeなど）に貼り付けて、あとは質問に答えていくだけです。

01準備するもの

  • パソコン（Windows / Mac どちらでも）
  • メールアドレス（クレジットカードは不要です）
  • AIコーディングツール（Claude Codeなど）
AIコーディングツール自体が初めての方へ

アカウントの作り方や、「AIにファイルを読ませる」の意味からは AIコーディング初心者向け・最初に用意するもの にまとめています。先にそちらをご覧ください。

02このアプリをダウンロードする

  1. GitHubのページを開く

    github.com/jagyamamoto/kairanban-app を開き、緑色の「Code」ボタンから「Download ZIP」を選んで展開します。gitに慣れていれば git clone でも構いません。

  2. AIコーディングツールでフォルダを開く

    展開してできたフォルダを、Claude Codeなどでいつも通り開きます。

03最初のプロンプト

下の内容を、【】の中だけ自分の団体の情報に書き換えて、そのままAIのチャット欄に貼り付けてください。

このリポジトリ(kairanban-app)を、私の団体用にセットアップしてください。 私はプログラミングの経験がありません。専門用語を使わず、 YesかNoで答えられる質問か、A/B/Cのような選択肢で聞いてください。 実行してほしいコマンドは、私がコピーして貼り付けるだけで済む形で、1つずつ出してください。 まず docs/セットアップ手順.md を読んでください。その手順に沿って、 ・ターミナルで実行するコマンドは、私がそのまま貼り付けられる形で提示する ・Cloudflareへのログインなど、私自身の操作が必要なところだけ、私にやってもらう ・団体名や会館情報など、私の団体の情報を先に聞いてから、AIが代わりにファイルを書き換える という進め方でお願いします。 私の団体名: 【ここに団体名を書く】 会館の名前・住所: 【ここに書く（無ければ「無し」でOK）】

この文章をそのまま選択してコピーし、AIのチャット欄に貼り付けてください。

04そのあとの流れ

ここから先はAIが主導します。Cloudflareアカウントの作成や、ログインのためのブラウザ操作など、 あなた自身にしかできない操作だけ、その都度指示が来ます。分からないことが出てきたら、 「わからない」とそのまま伝えれば、AIが言葉を変えて説明し直します。

全体で1〜2時間程度です。途中で中断しても、続きから再開できます。 詳しい手順の全文は セットアップ手順.md にあります。

05困ったとき

AIが3回試しても解決しない場合は、 GitHubのIssue に、今どういう状態か（何をしたか・何が起きたか）を書き込んでください。 エラーの文字は、そのままコピーして貼り付けるだけで大丈夫です。
