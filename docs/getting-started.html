AIコーディングツールがあると、だいぶ楽です。 ただ、無くても最後まで進めますし、そのぶん費用はかかりません。 まず、どちらで読むかを選んでください。選んだ道の手順だけが表示されます。

どちらで進みますか

あとから切り替えられます。違いとお金の詳しい比較は AIの契約は要りますか にまとめました。

準備するもの

  • パソコン（Windows / Mac どちらでも）
  • メールアドレス（クレジットカードは不要です）
AIを使う道
  • AIコーディングツール（Claude Code など）
AIの道具そのものが初めての方へ

アカウントの作り方や、「AIにファイルを読ませる」の意味からは AIコーディング初心者向け・最初に用意するもの にまとめています。先にそちらをご覧ください。

AIを使わない道
  • Windowsの方は git も（Macは最初から入っています）
    git-scm.com/download/win から入れて、 画面は何も変えずに「Next」を押していきます。 これが無いと最初のコマンドで止まります。
AIの契約は要りません

翻訳（やさしい日本語・英語・中国語・ベトナム語）は、Cloudflare に最初から付いてくる 無料の機能を使います。別の契約もAPIキーも要りません。 ごみの日や防災の情報も、管理画面に日本語で書くだけで5言語になります。

このアプリを手元に置く

  1. GitHubのページを開く

    github.com/jagyamamoto/kairanban-app を開き、緑色の「Code」ボタンから「Download ZIP」を選んで展開します。gitに慣れていれば git clone でも構いません。

  2. AIコーディングツールでフォルダを開く

    展開してできたフォルダを、Claude Codeなどでいつも通り開きます。

  3. ターミナルでそのフォルダに入る

    Windowsは「コマンドプロンプト」、Macは「ターミナル」を開きます。あとは手順書のコマンドを、上から1行ずつ貼ってEnterを押すだけです。

セットアップを進める

AIを使う道

先にセットアップ ウィザードを済ませた方は、そこで出る「AIに頼む・聞く」の文を貼ってください。 町会の情報が入った状態でAIが動くので、質問されずに進みます。まだの方は、下の文で構いません。

下の内容を、【】の中だけ自分の団体の情報に書き換えて、そのままAIのチャット欄に貼り付けてください。

このリポジトリ(kairanban-app)を、私の団体用にセットアップしてください。 私はプログラミングの経験がありません。専門用語を使わず、 YesかNoで答えられる質問か、A/B/Cのような選択肢で聞いてください。 実行してほしいコマンドは、私がコピーして貼り付けるだけで済む形で、1つずつ出してください。 まず docs/セットアップ手順.md を読んでください。その手順に沿って、 ・ターミナルで実行するコマンドは、私がそのまま貼り付けられる形で提示する ・Cloudflareへのログインなど、私自身の操作が必要なところだけ、私にやってもらう ・団体名や会館情報など、私の団体の情報を先に聞いてから、AIが代わりにファイルを書き換える という進め方でお願いします。 私の団体名: 【ここに団体名を書く】 会館の名前・住所: 【ここに書く（無ければ「無し」でOK）】

この文章をそのまま選択してコピーし、AIのチャット欄に貼り付けてください。

ここから先はAIが主導します。Cloudflareアカウントの作成や、ログインのためのブラウザ操作など、 あなた自身にしかできない操作だけ、その都度指示が来ます。 分からないことが出てきたら「わからない」とそのまま伝えれば、AIが言葉を変えて説明し直します。

AIを使わない道
いちばん楽な進め方

セットアップ ウィザードで、町会の名前や会館の場所を入れてください。 最後に「設定を保存」を押し、ZIPを解いたフォルダ（kairanban-app-main）の中の セットアップ.command（Mac）／セットアップ.bat（Windows）をダブルクリック。 保存した設定を自動で見つけて、あとは質問に答えるだけで公開まで進みます。コマンドを1行も打ちません。

手で進めたい方は セットアップ手順 を上から順に。11の段に分かれていて、ほとんどがコードを貼ってEnterを押すだけです。

自分で文字を書き換えるのは、次の2つのファイルだけです。

  • wrangler.jsonc … アプリの名前・データベースのID
  • src/shared/org.ts … 町会の名前・会館の場所・地名の対訳表
対訳表だけは必ず直してください

外国語に訳すとき、AIが地名をよその土地の実在する地名に置き換えることがあります。 実際に起きました。防災の案内では行き先が変わるので、実害になります。 分からなければ、町会名と会館名の2つだけでも入れてください。

ごみの日・防災を載せる

ここはどちらの道でも、AIの契約は要りません。 管理画面の「ページ」に日本語で書いて、「翻訳を更新」を押すだけです。 やさしい日本語・英語・中国語・ベトナム語のタブが自動で出ます。ファイルは触りません。

  1. 「ページ」を開く

    管理画面の左のメニューから「ページ」を押し、「+ 新しいページを作る」を押します。

  2. 日本語で書く

    スラッグに seikatsu、タイトルに「ごみの日・防災」、本文に自治体のホームページの内容を写します。最後に出典（どこの何年何月の情報か）を1行入れてください。

  3. 公開して、翻訳を更新する

    「下書きを作成」→「公開する」→「翻訳を更新」の順に押します。内容を直したら、そのつど「翻訳を更新」を押してください。押さないと古い訳が残ります。

AIを使う道
もっと詳しく載せたい場合

区が出している多言語のPDFまで一覧に並べたい場合は、 AIに手伝ってもらう に、区の公式サイトを読ませるための指示文を用意しています。

⚠ AIが書いた収集日と地名は、必ず区の公式サイトと見比べてください。 また、会員名簿・電話番号・住所をAIに貼らないでください。 このアプリは電話番号でログインするため、名簿が外に出るとなりすましができてしまいます。

困ったとき

AIを使う道

まずAIに、画面に出ているエラーの文字をそのまま貼って聞いてください。 3回試しても解決しない場合は、 GitHubのIssue に、今どういう状態か（何をしたか・何が起きたか）を書き込んでください。

AIを使わない道

手順書のいちばん下に「困ったとき」の表があります。よくある症状はそこで直ります。 それでも解決しないときは、 GitHubのIssue に、エラーの文字をそのまま貼って質問してください。

正直に申し上げると

このアプリにサポート窓口はありません。Issueの返事は早くないことがあります。 ここがいちばん、AIの有無で差が出るところです。 行き詰まったら、立ち上げの月だけAIを契約して、終わったら解約する手もあります。
