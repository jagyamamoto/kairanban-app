# AIに手伝ってもらう

**このページを読まなくても、アプリは立ち上がります。**
[セットアップ手順.md](セットアップ手順.md) だけで最後まで進みます。

ここは「AIの道具を持っている方なら、ここが省けます」という話です。

---

## 何が変わるか

| | AIの契約なし | AIの契約あり |
| --- | --- | --- |
| 立ち上げ（アプリが動くまで） | できます（1〜2時間） | 同じ（30分〜1時間） |
| 町会の名前・会館の場所 | 自分で書く | 同じ（すぐ終わります） |
| **ごみの日・防災** | 管理画面に**日本語で**書く。翻訳は自動 | **区の公式サイトを読ませて**、表・PDFリンクごと作らせる |
| 地名の対訳表 | 町会名と会館名だけ入れる | 町内の施設をまとめて作らせる |
| 使い方ページの画面写真 | 自分で撮って差し替える | 同じ（写真は自分で撮ります） |
| つまずいたとき | Issueで聞く（返事は遅いことがあります） | **その場で聞ける** |
| 町会に合わせた作り替え | できません | できます |

**いちばん差が出るのは、いちばん下の2つです。**
立ち上げそのものではなく、**詰まったときに聞ける相手がいるかどうか**です。

---

## ⚠ 先に、これだけは守ってください

- **会員名簿・電話番号・住所を、AIに貼らないでください。**
  このアプリは電話番号でログインします。名簿が外に出ると、なりすましができます。
- **AIが書いた地名・収集日は、必ず区の公式サイトと見比べてください。**
  AIは地名を、よその土地の実在する地名に置き換えることがあります。
  実際に起きました。防災の案内では、行き先が変わると実害になります。
- AIに「公開して」「デプロイして」と任せきりにしないでください。
  何が出るかは、自分の目で確かめてから公開します。

## コピペできる指示文

### 1. ごみの日・防災を作らせる

`src/shared/lifeinfo.ts` を自分の区の内容にします。
下の `〇〇` を自分の自治体・町会名に変えて貼ってください。

```
このリポジトリの src/shared/lifeinfo.ts を、〇〇区〇〇町の実際の内容に書き換えてください。

条件:
- 〇〇区の公式サイトを実際に読んで、そこに書いてある内容だけを使うこと。
  見つからなかった項目は、推測で埋めずに空にして、私に一覧で報告すること。
- ごみの収集日は、丁目によって違うことがある。〇〇町〇丁目のものを使うこと。
- 区が出している多言語PDFがあれば、言語ごとのURLを実際に開いて存在を確かめてから入れること。
  ない言語は、英語版にフォールバックして isFallback: true を付けること。
- ja / ja-easy / en / zh / vi の5言語すべてを埋めること。1つでも欠けると
  その言語の利用者に日本語が出る。
- 書き終えたら LIFE_INFO_ENABLED = true にして、npm run check が通ることを確認すること。
- 出典のURLと確認した日付を、ファイル冒頭のコメントに残すこと。
```

終わったら、**必ず自分で区の公式サイトと見比べてください。**

### 2. 地名の対訳表を作らせる

`src/shared/org.ts` の `glossary` です。

```
src/shared/org.ts の ORG.glossary を、〇〇区〇〇町の実際の地名・施設名に書き換えてください。

入れるもの:
- 区名・町名・町会名・会館名
- 近くの小中学校、公園、神社、駅（避難所や目印になるもの）

英語表記は、区の公式サイトや施設の公式サイトに載っている綴りを使うこと。
見つからない場合は、ヘボン式のローマ字にして、その旨を私に報告すること。
```

### 3. つまずいたときの聞き方

エラーが出たら、**画面に出ている文字をそのまま**貼るのがいちばん早いです。

```
Jag's Kairanban-app のセットアップ中です。下のコマンドでエラーが出ました。
原因と、次に私が打つコマンドを1つだけ教えてください。

打ったコマンド:
（ここに貼る）

出たエラー:
（ここに貼る）
```

### 4. 町会に合わせて作り替えたいとき

```
このリポジトリ（kairanban-app）に、〇〇という機能を足したいです。
まず、いま似た機能がどこにあるかを調べて、
どのファイルをどう変えることになるかを、コードを書く前に説明してください。
```

いきなり書かせず、**先に説明させる**と失敗が減ります。

## 作った内容を戻せるようにする

AIに書き換えさせる前に、これを打っておくと、いつでも元に戻せます。

```bash
git add -A && git commit -m "AIに書き換えさせる前の状態"
```

戻したくなったら、これです。

```bash
git reset --hard HEAD
```
