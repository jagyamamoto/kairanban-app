使い方ガイド（役員向け）

⚠ このページはひな形です。役員向けの操作(回覧の作成・会員の管理・会館予約の対応)の説明に書き換えてお使いください。
「ホーム画面に追加する」手順は、アプリを開くと画面が写真つきで案内します（右上の「☰」→「最初の設定」）。

1. このアプリでできること

回覧・お知らせを読む / 会館の予約 / 会合の出欠 / 町会資料・行事の写真を見る / ごみの日・防災情報を見る。費用はかかりません。

2. ホーム画面に追加する

アプリを開くと、お使いのスマホに合わせて押すものを1つずつ写真で案内します。アプリの右上の「☰」→「最初の設定」からいつでもやり直せます。

3. 会員登録・ログイン

「会員登録」から、お名前・住所・電話番号を登録します。次回からは電話番号でログインできます。

4. 困ったときは

アイコンを見失った→「☰」の「最初の設定」。通知が来ない→通知の確認で「許可」を押したかご確認ください。分からないことは町会役員へどうぞ。
