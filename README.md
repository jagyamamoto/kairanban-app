# kairanban-app（回覧板）

**町内会・自治会のための、無料で使えるスマホアプリです。**

紙の回覧板を待たずにお知らせを読めて、会館の予約も、会合の出欠も、スマホひとつで済みます。
町会の役員さんが自分たちで立ち上げて、自分たちで運営できることを目指しています。

サーバー代は、ふつうの町会の規模なら **月0円**（Cloudflare の無料枠に収まります）。

## 🖐 さわって試せます

**<https://kairanban-demo.jagyamamoto.workers.dev>**

架空の町会・架空の会員のデータが入っています。自由に触っていただけます
（入力した内容は24時間ごとに元へ戻ります）。

会員として中を見るには、「ログイン」を押して電話番号にこちらを入れてください。

| 電話番号 | 立場 | 見えるもの |
| --- | --- | --- |
| `09000000001` | 管理者 | すべて（会員管理・回覧の作成・入会申込の処理） |
| `09000000003` | 役員（回覧担当） | 回覧の作成、役員向けの資料 |
| `09000000008` | ふつうの会員 | 回覧を読む、会館を予約する、出欠を答える |

会館予約と入会申込は、**ログインしなくても**お試しいただけます。

## できること

| 機能 | 内容 |
| --- | --- |
| **回覧** | お知らせを配信し、誰が確認したかを把握できます。メールでも同じ内容が届きます |
| **会館予約** | 空き状況カレンダーから申し込み。**ログイン不要**なので町会員以外の方も使えます |
| **会合の出欠** | 出欠と人数・食事の数を集計。未回答の方へまとめてお知らせできます |
| **町会資料** | 規約・議事録などを置けます。誰に見せるかを細かく決められます |
| **ブログ** | 行事の写真を共有します。**一般公開は一切できない**設計です |
| **ごみの日・防災** | 自治体のごみ収集日や避難所の情報を載せられます |
| **多言語** | 日本語・やさしい日本語・英語・中国語・ベトナム語（AIが自動翻訳） |
| **通知** | 新しい回覧をスマホの通知でお知らせ。アイコンに未読の数も出ます |

### 高齢の会員が使えることを最優先に設計しています

- 文字は大きく、押すところは大きく（指で押せる44px以上）
- 「ホーム画面に追加」の手順を、**押すものの写真つきで画面の上に出し続けます**
  （iPhoneの共有画面が開いても隠れない位置に出ることを実機で確認済み）
- 入力もれがあったら、**その欄まで自動で移動して赤く囲みます**
- 状態を色だけで表さず、記号（○ △ ●）も併記します

## 動かすのに必要なもの

- Cloudflare のアカウント（無料。クレジットカードの登録は不要です）
- Node.js 20 以上
- メールを送る場合のみ [Resend](https://resend.com) のアカウント（無料枠あり）

## 立ち上げかた

```bash
git clone https://github.com/jagyamamoto/kairanban-app.git
cd kairanban-app
npm install
```

**手順は [docs/セットアップ手順.md](docs/セットアップ手順.md) に、1動作ずつ書いてあります。**
プログラムの経験がない方でも進められるように書いています。

書き換える場所は、次の4つだけです。

| ファイル | 何を書くか |
| --- | --- |
| `src/shared/org.ts` | 町会名・会館の場所・会員の区分の呼び名 |
| `wrangler.jsonc` | アプリ名・データベースID・メールの送信元 |
| `src/shared/lifeinfo.ts` | ごみの日・避難所・自治体へのリンク |
| `src/server/areaalerts.ts` | 自治体の防災メールを取り込む場合のみ |

## ⚠ 導入する前に必ずお読みください（安全のこと）

### ログインは電話番号だけです — 利便性とリスクのトレードオフ

このアプリは、**電話番号を入れるだけでログインできます**。パスワードはありません。
これは技術的な手抜きではなく、**意図的に選んだトレードオフ**です。

| | |
| --- | --- |
| **得たもの（利便性）** | 70代・80代の方が自力でログインできる。パスワードを覚える・入力する・再設定する必要がない。**使えなければ回覧は届かない**という現実への回答です |
| **払ったもの（リスク）** | **電話番号を知っている人は、その方になりすましてログインできます。** その方の氏名・住所・電話番号と、見られる回覧・資料・写真が見えます |

電話番号は秘密ではありません（名簿・連絡網・年賀状などから知りえます）。
総当たりは1時間20回までに制限していますが、**番号を知っている人には効きません**。

したがって、**電話番号入りの会員名簿を外部に出さない運用**が前提になります。

**⚠ 導入する町会が、自分の事情で判断してください。**
判断の材料、検討して見送った他の方式、運用上の注意は
**[docs/ログイン方式について.md](docs/ログイン方式について.md)** に詳しく書いています。

> 🙋 **より良い方法を募集しています。**
> ここは「解決済み」ではありません。高齢の方が完走できて、かつ安全性が上がる方法を探しています。
> コードがなくても、考え方だけ・実体験だけでも大歓迎です。Issue にお寄せください。

### そのほか

- 通知はロック画面に「〇〇さん、「（回覧の見出し）」の回覧通知があります。」と出ます。
  スマホを覗ける人には、お名前と回覧の見出しが見えます。
- 「どなたでも見られる」設定にした回覧は、**本文がそのまま誰でも読めます**。
  本文に個人の連絡先を書かないでください。
- 写真・ブログは**一般公開できない設計**です（ログインした会員だけが見られます）。
- 使い方ページ（`public/help/`）は**ログインしなくても誰でも見られます**。
  ここに置く画面写真には、**本物の会員情報を絶対に写さないでください**。
  確認用のツールを用意しています: `bash tools/scrub-check.sh`

## サポートについて

このアプリは、ひとつの町会の実際の困りごとから生まれたものを、
そのまま使えるように整えて公開しているものです。**個人が空いた時間で管理しています。**

- Issue・Pull Request は歓迎します。ただし **返信は必ずしも早くありません**。
- **動作の保証・導入の代行・障害対応の約束はできません。**
- 各町会での運用や、個人情報の取り扱いの責任は、**導入した町会が負う**ことになります。

改善のご報告、とくに「実際に導入してこう困った」という話は、とてもありがたいです。
