# ログイン方式について — 利便性とリスクのトレードオフ

**このアプリは、電話番号を入れるだけでログインできます。パスワードはありません。**

これは技術的な手抜きではなく、**意図的に選んだトレードオフ**です。
選んだ理由と、引き受けているリスクの両方をここに書きます。
そのうえで、**より良い方法の提案を募集しています**（このページの最後をご覧ください）。

---

## 1. なぜこうしたか（利便性の側）

町内会アプリの利用者の中心は、**70代・80代の方**です。実際に見えてきたことは次のとおりです。

- パスワードを作れない・覚えられない・書き留めた紙をなくす
- 記号や大文字小文字の混在した文字列を、小さなキーボードで入力できない
- 「パスワードを忘れた」の再設定は、メールを開く操作が必要で、そこでまた詰まる
- 二段階認証は、SMSアプリとブラウザを行き来する時点で完走できない

**ログインできなければ、アプリは存在しないのと同じです。**
どれだけ安全に作っても、使われなければ回覧は届きません。

電話番号なら、ご自分の番号を覚えている方が多く、数字だけで入力でき、
入力欄も数字キーパッドが出ます。**「使えないから諦める」を最小にする**選択でした。

## 2. 何を引き受けているか（リスクの側）

**電話番号を知っている人は、その方になりすましてログインできます。**

なりすました人が見られるもの:

- その方の氏名・住所・電話番号・メールアドレス
- その方が見られる回覧の全文
- その方の権限で見られる町会資料・行事の写真
- その方の会館予約の状況

**電話番号は「秘密」ではありません。** 名簿、年賀状、地域の連絡網、家族、
以前の勤務先など、知りうる人はたくさんいます。ここが最大の弱点です。

### やっている対策

| 対策 | 内容 | 限界 |
| --- | --- | --- |
| 回数制限 | 失敗ログインを1時間20回/接続元まで | **番号を知っている人は1回で成功するので効かない** |
| 記録 | ログイン成功を監査ログに残す | 事後に分かるだけで、防げない |
| 権限の分離 | 役員・管理者の機能は別権限。一般会員はなりすまされても管理画面に入れない | 被害の範囲を狭めるだけ |
| 写真の保護 | ブログ・写真は一般公開できない設計 | ログインした人には見える |

### したがって、運用でこうしてください

- **電話番号入りの会員名簿を、外部に出さない・共有ドライブに置かない**
- 回覧の本文に、個人の連絡先を書かない
- 退会・転居した方は、管理画面から速やかに退会にする
- 「誰が見られるか」の設定を、必要最小限にする

## 3. 検討して見送った案

| 案 | 内容 | 見送った理由 |
| --- | --- | --- |
| パスワード | 一般的な方式 | 上記1のとおり、対象利用者が完走できない |
| メールの確認番号 | 番号をメールで送る | メールを持たない方が多い。メールを開く操作でつまずく |
| SMSの確認番号 | 番号をSMSで送る | 費用がかかる。アプリ間の移動で完走できない方が出る |
| 役員が渡す合言葉 | 初回だけ合言葉を入れる | 有力。ただし配布と再発行の運用負担が役員にかかる |
| パスキー | 生体認証 | 対応端末が限られ、機種変更時の移行で詰む |

**「役員が渡す合言葉」は現実的な次の一手**だと考えていますが、
「配る」「なくした人に再発行する」という**人間側の運用**が続くかどうかが課題です。

## 4. あなたの町会はどう判断すべきか

導入する町会が、**自分で判断してください**。判断の材料:

- **そのままで良い場合**: 会員名簿の管理が徹底されていて、
  扱う情報が「回覧のお知らせ」中心で、機微な情報を載せない運用ができる
- **対策が必要な場合**: 資料に会計情報や個人の事情を含める、
  名簿が広く出回っている、過去にトラブルがあった

対策が必要な場合は、下記の提案募集にご参加いただくか、
Issue で相談してください。

## 5. 🙋 より良い方法を提案してください

**ここは「解決済み」ではありません。** より良い方法を探しています。

こういう提案を歓迎します。

- **高齢者が完走できて、かつ安全性が上がる方法**
  （実際に高齢の方に試した結果があれば、なお貴重です）
- **合言葉方式の、運用が破綻しない配り方**
- **段階的な方式**（ふだんは電話番号、資料や写真を見るときだけ追加確認、など）
- **「そもそもこの判断は間違っている」という指摘**（根拠があるとありがたいです）
- **他の自治体・団体アプリでの実例**

提案は **Issue に「ログイン方式」のラベルで**お寄せください。
コードがなくても、考え方だけで十分です。

実際に高齢の方に使ってもらった経験をお持ちの方の声を、いちばん求めています。
