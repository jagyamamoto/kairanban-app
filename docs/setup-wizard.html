ウィザード

町会の名前や会館の場所を入れると、書き換える必要のある設定ファイル2つと、 あなたのパソコン（Mac / Windows）に合わせた手順ができます。 AIの契約は要りません。入れた内容はこのブラウザにだけ残り、どこにも送られません。

1 / 6あなたのパソコン

手順のコマンドが少し違うので、先に選びます。

2 / 6用意するもの

いま入っているかを確かめます。入っていなくても、ここで入れ方が出ます。

確かめ方: 「ターミナル」「コマンドプロンプト」を開いて、次を貼ってEnter。v20.x.x のような数字が出れば入っています。

node -v
Node.js を入れる
  1. https://nodejs.org/ja を開く
  2. 左側の「推奨版」のボタンを押してダウンロード
  3. ダウンロードしたファイルを開き、そのまま「次へ」を押していく
  4. ターミナルコマンドプロンプトをいちど閉じて開き直し、もう一度 node -v

Windowsには最初から入っていません。これが無いと最初のコマンドで止まります。確かめ方: 次を貼ってEnter。

git --version
git を入れる
  1. https://git-scm.com/download/win を開く
  2. ダウンロードされたファイルを開く
  3. 画面が何度も出ますが、すべて何も変えずに「Next」。最後に「Install」
  4. コマンドプロンプトをいちど閉じて開き直し、もう一度 git --version
アカウントを作る（クレジットカードは要りません）
  1. https://dash.cloudflare.com/sign-up を開く
  2. メールアドレスとパスワードを入れて「Sign Up」
  3. 届いたメールのリンクを押して、登録を完了する

3 / 6町会の情報

ここで入れたものが、そのまま設定ファイルになります。あとから直せますので、分かるところから。

町会の名前を入れてください

画面の見出しと、メールの差出人に出ます。

6文字くらいまでにしてください

スマホのホーム画面で、アイコンの下に出ます。全角6文字まで。

半角の小文字・数字・ハイフンだけ。先頭は文字で。

アプリのURLの一部になります（https://midori-3.〇〇.workers.dev）。

入会案内に出ます。そのままでも構いません。

会館（集会所）

35.681236 のような数字で

139.767125 のような数字で

緯度・経度の調べ方（1分）
  1. Googleマップ で会館を探す
  2. 会館の場所を右クリック（スマホは長押し）
  3. いちばん上に出る数字（例 35.681236, 139.767125）を押すとコピーされる
  4. 左の数字を「緯度」、右の数字を「経度」に貼る

分からなければ空のままで大丈夫です。地図の中心が東京駅になるだけで、ほかは動きます。あとから直せます。

会員の区分の呼び名

地域の呼び方に合わせて直せます（「寿会」「松柏会」など）。使わない区分はそのままで構いません。

何の区分か表示する呼び名

地名・施設名の対訳表

ここは必ず入れてください

外国語に訳すとき、AIが地名をよその土地の実在する地名に置き換えることがあります。実際に起きました。防災の案内では行き先が変わるので実害になります。 町会名と会館名の2つだけでも入れてください。英語の書き方が分からなければ、ローマ字で構いません。

日本語英語での書き方

4 / 6使う機能

アプリの通知だけなら要りません。あとから足せます。

メールには独自ドメインが要ります

年1,000〜2,000円くらいのドメイン（例: midori-chokai.jp）と、その設定変更が要ります。 設定を間違えると町会のホームページやメールが止まることがあります。不安なら、あとから詳しい方と一緒に進めてください。ここは「使う」にしても、実際の設定は最後の段の「あとから」に出ます。

ドメインの認証が済んだアドレス

実在する受信箱にしてください

ごみの日・防災は、ここでは聞きません

アプリができてから、管理画面の「ページ」に日本語で書いて「翻訳を更新」を押すだけです。ファイルを触りません。5言語になります。

5 / 6コマンドの結果を貼る（あとでも構いません）

設定ファイルには、コマンドを実行しないと分からない値が2つあります。 先に済ませておくと、設定ファイルが穴なしで完成します。まだなら飛ばして構いません。最後の手順の中で同じことをします。

Cloudflareにログイン済み（npx wrangler login）で、アプリのフォルダの中で次を実行し、出てきた文字を全部下に貼ってください。IDだけ拾います。

npx wrangler d1 create midori-3

node tools/gen-vapid.mjs
